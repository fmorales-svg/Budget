# Budget App

Repositorio listo para publicar la aplicación estática en GitHub Pages.

## Publicar la app

1. Guarda el contenido de `Budget App - Standalone.html` en este repositorio con el nombre `index.html`.
2. Sube los cambios a GitHub:

	```bash
	git add .
	git commit -m "Add budget app"
	git push -u origin main
	```

3. En GitHub, abre **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`.

La aplicación quedará disponible en:

```text
https://TU_USUARIO.github.io/NOMBRE_DEL_REPOSITORIO/
```
